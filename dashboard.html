为什么桌面任务显示“最后记录运行中”？

依据本机主对话的开始/结束记录，不把“最近对话”或“客户端已打开”当作运行中。客户端异常退出可能没写结束记录，因此这里不是实时运行保证；重启时只恢复显示，不补发历史完成通知。

第一次使用？展开查看飞书设置步骤
  1. 在飞书中新建一个群，只有你自己也可以。
  2. 打开群聊右上角 … → 设置 → 群机器人 → 添加机器人。
  3. 选择 自定义机器人，名称可填写“Codex 通知”。
  4. 安全设置建议选择“关键词”，关键词填写 Codex；暂时不要开启签名校验。
  5. 创建后复制完整 Webhook 地址，粘贴到上方，点击“保存并发送测试消息”。

Webhook 相当于群消息密码，不要发给别人或贴到公开网页。

在飞书里回复 Codex

自建应用机器人使用长连接接收回复。App Secret 只会以 Windows 当前用户加密方式保存在本机，不会回显。

尚未配置

连接后，在机器人所在群里 @机器人发送“绑定”。以后回复机器人通知并 @机器人，内容会追加到绑定的原 Codex 对话，不会新建对话；私聊机器人时可直接回复。

本轮结果图片回传（默认开启）

Codex 图片生成结果会自动回传到所有对话对应的飞书通知，不需要填写目录；本机 Markdown 图片仍需位于下面授权的具体目录内。每轮最多6张，单张不超过10MB，支持 PNG/JPEG/WebP/GIF；不扫描文件夹，不下载网络图片。需要自建应用机器人及图片上传资源权限；Webhook 不支持此功能。
