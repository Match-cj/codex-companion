第一次使用？展开查看飞书设置步骤
  1. 在飞书中新建一个群，只有你自己也可以。
  2. 打开群聊右上角 … → 设置 → 群机器人 → 添加机器人。
  3. 选择 自定义机器人，名称可填写“Codex 通知”。
  4. 安全设置建议选择“关键词”，关键词填写 Codex；暂时不要开启签名校验。
  5. 创建后复制完整 Webhook 地址，粘贴到上方，点击“保存并发送测试消息”。

Webhook 相当于群消息密码，不要发给别人或贴到公开网页。

Webhook 与应用机器人区别

Webhook 自定义机器人：单向发送通知，配置简单；不能接收回复，不能执行继续、停止、切换账号，也不支持图片和文件回传。

飞书自建应用机器人：配置 App ID、App Secret 并建立长连接，可接收回复、控制任务和回传图片/文件，需要发布应用并验证操作者。

你现在使用的是自建应用机器人方式，不是 Webhook；Webhook 只用于单向通知。

在飞书里回复 Codex

自建应用机器人使用长连接接收回复。App Secret 只会以 Windows 当前用户加密方式保存在本机，不会回显。

桌面端自动重试（模型繁忙时自动点「重试」）

开启后，当 Codex 桌面端提示「模型繁忙 / Selected model is at capacity」并出现重试按钮时，Companion 会自动按下它：不改动对话内容、不追加提示词、不更换模型，等于替你手动点一下。仅 Windows 桌面端可用。

自动重试期间，「模型繁忙」这类失败不再逐条通知，只在超过上面设定的时间还没跑完时提醒一次，真正跑完再通知结果。点击优先走系统消息通道（不动鼠标）；只有客户端不支持时才改用鼠标，用完立刻把指针放回原位，而且你正在移动鼠标时它会跳过、等下一轮。

接管会关闭 Codex 桌面端、把对话转到 Companion 后台继续；与上面的自动重试互斥，二选一。

什么时候点不到：Windows 锁屏（Win+L、屏保恢复时需要输入密码）之后桌面被切走，自动重试会点不到按钮；远程桌面断开、电脑睡眠/休眠同理。想让它一直工作：电源设置里把「睡眠」设为从不、关闭需要密码的锁屏，只让显示器自己熄屏即可（熄屏不影响，锁屏才影响）。

额度用尽自动换号（账号接力）

任务因为额度用尽失败时（提示 usage limit / 购买额度），Companion 会发一条飞书消息：列出哪个账号没额度、其它账号还剩多少，回复 切换（切换账号、切换账号并继续 也一样）就自动选额度最多的账号继续这个任务；回复 切换 账号名 指定账号；回复 切换 账号名 不继续 只换号。只有 5 小时额度真的还有剩余的账号才会被自动选中，读不到额度时不会乱选。

不勾选（默认）= 先发消息问你，你回一句再切；勾选 = 自动切并继续，切换成功后会告诉你切到了哪个账号。飞书里也可以直接回复 自动切换 开启 / 自动切换 关闭 修改。自动切换最多连续 3 次，避免两个账号来回空转。

对话收尾：上下文快满时怎么办

主对话上下文用到 70% / 85% / 95% 时，Companion 会各提醒一次（通知类型「上下文接近上限」，可在通知表格里关掉）。它只提醒，不会自动开新对话、也不会自动往你的对话里插话——自动插话可能打断正在跑的任务，还可能改坏内容。收尾由你决定，但提示词已经准备好了：

粘到 Codex 里让它生成摘要 → 把摘要复制出来 → 新建对话粘进去继续。
飞书消息收件箱（把消息给本机 AI 读，不用等管理员审核）

Companion 收到的每一条飞书消息都会自动存到本机文件里（最新在最后）：。这样你不用等企业管理员审核任何应用——直接让本机 AI（Codex / WorkBuddy / 任意工具）读这份文件就能拿到消息内容。文件只在这台电脑上，不会上传到任何地方。

在飞书里回复「收件箱」也能在手机上看到最近 10 条。
