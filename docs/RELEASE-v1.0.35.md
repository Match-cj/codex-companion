# Release v1.0.35

版本 / 日期 / 提交号：1.0.35 / 2026-11-05 / 见 tag `v1.0.35`

## 用户可见变化

- 浮窗不再出现在 Alt+Tab / Win+Tab 任务切换界面（1.0.33）。
- 计划任务新增「每 5 分钟自检」：后台或浮窗意外退出后 5 分钟内自动拉起，无需人工干预（1.0.35）。实测杀掉后台约 70 秒恢复。
- 启动器加固：归一化大小写重复的代理环境变量（`HTTP_PROXY` 与 `http_proxy` 并存时曾导致启动失败）；`launcher.log` 版本号改为从 package.json 读取，不再显示硬编码旧版本（1.0.34）。
- README 重构为普通用户/开发者分层，新增真实浮窗截图主图（1.0.34）。
- 打包脚本修复：显式 UTF-8 读取 package.json，兼容 Windows PowerShell 5.1 构建环境。

## 验证

- 本地测试：`npm test` 全过（125 项，1.0.32 基线）。
- 部署验证：安装版经 `Deploy to Installed.ps1` 同步并重启，`/api/health` 返回 `1.0.35`。
- 自愈验证：故意终止后台进程，计划任务在约 70 秒内自动恢复服务与浮窗。
