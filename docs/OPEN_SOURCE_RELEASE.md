# 公开发行准备清单

更新：2026-10-26；开发版本：1.0.8。此清单区分本地准备与实际公开发布，不代表已完成安全审计或新电脑验收。

## 本地已完成

- [x] MIT 许可证、贡献指南、安全报告指引、隐私说明。
- [x] 依赖锁文件、Windows CI 配置和不读取真实账号的浮窗自检。
- [x] 主会话话题去重、子代理通知过滤、提前额度重置检测的自动回归。
- [x] v1.0.7 双击账号切换获用户现场验收。
- [x] 仓库运行数据/安装包忽略规则、安装载荷白名单和 SHA256 校验。
- [x] 反馈、PR 和发布记录模板。

## 发布前仍需核实

- [ ] 全新 Windows 用户环境：首次安装、启动、账号登录、升级回滚、卸载保留/删除选项。
- [ ] 飞书测试群：单主会话多轮不新增重复话题，过程/子代理不通知，结果图片和手机回复定位正确。
- [ ] 真实提前重置事件：旧计划时间未到、额度回到满额只通知一次；正常到期只有原有预告。
- [ ] Git 全历史敏感数据审计。工作树未匹配到个人账号标识的初步检查不代表历史安全。
- [ ] 全部间接依赖、官方运行时、图标的来源与许可证确认，详见 `THIRD_PARTY.md`。
- [ ] 明确未签名安装包的分发提示；如增加代码签名，核验签名与校验和。
- [ ] 在目标远程仓库执行 CI；本地测试通过不代表远程 CI 已运行。
- [ ] 维护者确认仓库公开、标签和 Release。没有自动推送、改可见性或发布外部消息。
