# Release v1.0.36

版本 / 日期 / 提交号：1.0.36 / 2026-11-05 / `7ad45d8`

## 用户可见变化

- **修复全新电脑安装失败**：1.0.35 及更早的安装包在中文 Windows 上全新安装时，最后一步会弹「Runtime error (at 1:932)」并回滚。根因是 Windows PowerShell 5.1 读取含中文的 `package.json` 未指定 UTF-8（同事电脑实测复现）。已修复并在本机 125 项测试全过后重新打包。
- **首次启动自动导入本机 Codex 登录**：安装后若这台电脑已在 Codex 客户端登录过，后台首次启动会自动把客户端凭据导入 Companion 加密账号库并推送确认通知——省去手动登录一步。每台电脑只做一次；用户手动删除过的账号不会被恢复；网页上的手动「导入本机已登录账号」按钮保留。
